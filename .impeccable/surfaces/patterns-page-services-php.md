# Services page

Mode: Persuade, inside the Quote Book world (see templates/front-page.html). Job: a prospect picks the service that fits and books a call. Sits under the Page template's title.

- Intro: one short paragraph directly under the page title; no label above it, no repeated heading.
- Services Grid: ruled cards, not shadowed tiles. Each has icon, title, one sentence, link. Four to six cards, wraps to one column at 375px; titles and sentences tolerate long text.
- How It Works: three steps, red serial numerals 01-03 as the only ornament, set as numbered quote lines, stacking on small screens.
- Then testimonial, FAQ, call to action; each section hands over with a ruled edge or a field change, not both.
- Copy is placeholder for a generic service business, naming its slot. Every string translatable. Core blocks only.
- Anti-goals: no eyebrow labels, no centered hero, no gradient or glass cards, no color-bound ornament.
